## Architecture

- Use Expo/React Native
- Use the Microsoft packages to support macOS and Windows
- The API runs as an Express app on an Amazon Lambda Web Function (no adapter, no API Gateway). Cognito JWTs are validated in the app.
- Write an OpenAPI definition file first. Use [openapi-typescript](https://github.com/openapi-ts/openapi-typescript) to generate types from it and [express-openapi-validator](https://github.com/cdimascio/express-openapi-validator) to ensure compatibility.
- Use Amazon Cognito for authentication
- Add the Microsoft external/social provider to Cognito
- Keep the logic layers independent of the infrastructure. domain, application, http and mcp never import an SDK or anything from infrastructure; they depend only on ports (interfaces) for data (one repository per aggregate, grouped as a DataStore), media storage (MediaStorage), authentication (Authenticator and UserDirectory) and realtime delivery (ChangeChannel). Each port has interchangeable providers under infrastructure/<provider> (aws: DynamoDB, S3, Cognito, API Gateway; local: SQLite, disk, built-in or enforced user, in-process WebSocket; plus in-memory for tests). A provider owns its own configuration and is chosen by environment variable (for example DATA_PROVIDER, MEDIA_PROVIDER, AUTH_PROVIDER, REALTIME_PROVIDER), so adding a database or storage backend means adding one provider and no changes elsewhere. Ports must not leak provider concepts (no presigned S3 forms or Dynamo keys in their signatures). Every provider of a port must pass the same shared contract test suite. AWS serverless stays a first-class option: src/lambda.ts and src/server.ts are thin entry points that only compose providers, and each bundle contains only the providers it uses

## Self-hosting

Another To Do must be easy to self-host. The repository ships a Dockerfile and docker-compose.yml (one container: API, SQLite, local photo storage, WebSocket real time and the web app, served by src/server.ts). Users are assumed not to use Terraform and are responsible for their own domain and TLS. The guides are docs/self-hosting.md and docs/azure-app-registration.md; keep both current when a variable changes.

Configuration is environment variables only: PUBLIC_API_URL, ADMIN_USERNAME and ADMIN_PASSWORD (when set, resets the admin password on every start; when blank a random one is printed once), ENFORCED_USERNAME (bypasses authentication entirely and is picked automatically as the identity provider when set), ENFORCED_SERVER_URL (locks the bundled web app to a server, blank means its own), SERVER_NOTICE (the yellow notice), CORS_ORIGINS, AZURE_CLIENT_ID, AZURE_CLIENT_SECRET and AZURE_TENANT_ID (Sign in with Microsoft is on only when both the id and secret are set), SECRET_KEY, PORT, DATA_DIR and the provider variables DATA_PROVIDER, MEDIA_PROVIDER, AUTH_PROVIDER and REALTIME_PROVIDER.

The clients prompt for the server URL unless it is enforced. Most people will use the official client builds from GitHub and point them at their server.

The demo gets no special treatment: it is a deployment that uses the same variables. Do not add demo flags, demo credentials or a separate demo sign-in path to the code; the only demo-specific behavior is the yellow notice, which is shown whenever the server sends one.

Not done yet: publishing the container image to a registry (compose builds it locally), a generic OIDC auth provider, and user management beyond POST /auth/users.

## Repo context

Web Functions are only in us-east-1, us-east-2, us-west-2, ap-northeast-1 and eu-west-1 (default region is us-east-1)
- apps/api/openapi.json is the source of truth. Run `pnpm run generate` after editing it to refresh src/generated/api.ts. express-openapi-validator validates requests and responses at runtime
- Layers: domain (immutable Task and TodoList, repository interfaces), application (TaskService, TaskChanges), infrastructure (providers: aws, local, memory, shared), composition (Platform, ProviderRegistry, PlatformFactory), http (controllers, Authenticator, ErrorHandler), mcp (McpServer JSON-RPC, tools)
